# Trackboxd

The Letterboxd for music. Rate songs and albums, write reviews, comment on any moment in a track, and keep a listening diary.

Live at [trackboxd.com](https://www.trackboxd.com). Next.js 14 on Vercel, Supabase for data and auth, Spotify's catalogue for tracks.

Free, no paywall.
